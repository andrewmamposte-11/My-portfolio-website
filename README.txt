ANDREW N. MAMPOSTE - PERSONAL PORTFOLIO (HTML + CSS only, no JavaScript)

FILES
- index.html   The whole website (Home, About, Skills, Projects, Achievements, Hobbies, Contact)
- style.css    All colors, layout, themes, and animations
- assets/      all pictures in one folder: profile.jpg, academic-achievements.jpg, and the two certificate pictures (JPG) with their PDF copies

HOW TO OPEN
1. Extract the ZIP file.
2. Double-click index.html (or open the folder in Visual Studio Code and use Live Server).
3. Keep index.html, style.css, and the assets folder together.

FEATURES
- Four space themes: Cosmic, Galaxy, Meteor Shower, and Black Hole.
  Use the THEME buttons at the bottom of the screen (swipe the bar sideways on a phone).
  The choice resets when the page is refreshed (no JavaScript means nothing can be saved).
- Move the mouse over the page: the background squares light up and slowly fade.
  This works on desktop with a mouse; touch screens do not have a hover cursor.
- Every box, card, and button glows around its edge when the cursor touches it.
- Click a certificate or the achievements photo to see it enlarged. Click outside it or press Close to go back.
- The contact form opens the visitor's email app with the message ready to send (plain HTML cannot send emails by itself).

EDITING NOTES
- Replace the Facebook link in index.html (search for facebook.com) with your exact profile URL.
- Location is set to Calapan City, Oriental Mindoro in two places. Search "Calapan" to change both.
- To change the profile picture, replace assets/profile.jpg (keep the same file name).
- Fonts come from Google Fonts and need internet; fallbacks are used when offline.
- Theme colors are the variables at the top of style.css (--c1, --c2, --c3).
